Prompt da capa

Crie uma capa quadrada de 1024 × 1024 px para um jogo educativo sobre [TEMA]. Público-alvo: [PÚBLICO]. Use estilo anime 3D fofo, moderno, científico e acolhedor. Inclua o título “[NOME DO JOGO]”. Use alta nitidez, contraste adequado e elementos grandes.

Prompt do fundo

Crie um fundo horizontal de 1920 × 1080 px para um jogo educativo sobre [TEMA]. Use estilo anime 3D fofo e científico, com tons pastéis. Não inclua textos e deixe áreas livres para cards, botões e perguntas.

Prompt das imagens do jogo

Crie [QUANTIDADE] imagens educativas diferentes sobre [TEMA]. Cada imagem deve representar um conceito. Use o mesmo estilo, paleta e iluminação. Formato quadrado, sem texto pequeno, com o elemento principal centralizado. Público: [PÚBLICO].
5

Selecionar sons e efeitos

Use sons curtos, suaves e opcionais, sempre verificando a licença.

clique.mp3   → botões
acerto.mp3   → resposta correta
erro.mp3     → resposta incorreta
vitoria.mp3  → conclusão
ambiente.mp3 → trilha opcional

O usuário deve poder desligar o som. O jogo precisa ser compreensível sem áudio.

6

Enviar os assets

Entre em cada pasta e use Add file → Upload files.

assets/img/capa.png
assets/img/fundo.png
assets/img/jogo/imagem01.png
assets/audio/clique.mp3
assets/icons/icon-192.png

Use nomes em letras minúsculas, sem espaços e sem acentos.

7

Gerar o código com IA

Use o prompt completo abaixo.

Crie um jogo educativo completo e acessível em HTML, CSS e JavaScript puro.

Não use backend, banco de dados ou frameworks.

Tipo: [TIPO].
Tema: [TEMA].
Público: [PÚBLICO].
Conteúdo: [CONTEÚDO].

O projeto deve funcionar no GitHub Pages e como PWA instalável.

Entregue, separadamente e por completo:
1. index.html
2. style.css
3. app.js
4. manifest.json
5. sw.js

Use imagens de assets/img e assets/img/jogo, sons de assets/audio e ícones de assets/icons.

Inclua tela inicial, instruções, iniciar, reiniciar, pontuação, mensagem final, sons opcionais, controle de volume, fonte ampliável, alto contraste, modo escuro, botões grandes, textos alternativos, navegação por teclado, VLibras, responsividade, ausência de tempo obrigatório, salvamento local, manifest e service worker válidos.
8

Criar os arquivos

No GitHub, crie index.html, style.css, app.js, manifest.json e sw.js.

9

Publicar no GitHub Pages

Settings → Pages → Deploy from a branch → main → /root → Save.
