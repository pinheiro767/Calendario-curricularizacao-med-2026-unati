# Semana 6 — Crie seu jogo PWA

1. Envie todos os arquivos e pastas deste pacote para um repositório público do GitHub.
2. Abra Settings → Pages.
3. Selecione Deploy from a branch.
4. Escolha main e /root.
5. Salve e aguarde o link público.

O aplicativo funciona em computador, tablet e celular, salva o progresso no dispositivo e pode ser instalado como PWA.
